# 🚗 GearUP — Vehicle Rental System

**GearUP** is a modern web-based platform designed to simplify vehicle rentals for users and rental companies.  
It enables customers to **search, view, and book vehicles online**, while providing administrators with tools to manage listings and bookings efficiently.

Developed as part of the **Studio 3** course at **Otago Polytechnic (Future Skills Campus)**, this project follows a **hybrid project management methodology**, combining **Waterfall** for planning and **Agile Scrum** for implementation and testing.

## 🧭 Background and Purpose

The **GearUP Vehicle Rental System** is a group project aimed at addressing inefficiencies in how small rental companies manage bookings.  
Many still rely on manual methods or outdated websites without real-time data.  
GearUP solves this by providing an intuitive platform where:

- Customers can **search, compare, and book vehicles** in real time.  
- Administrators can **add, edit, or remove listings** and track bookings.  

This project also helps the team apply key concepts in **web development**, **Agile project management**, and **client collaboration**, simulating a professional software development environment.

---

## 🎯 Project Objectives

- Develop a responsive web app where users can view, search, and book vehicles.  
- Design an **Admin Panel** for vehicle management and bookings.  
- Implement **secure login and registration** for customers and admins.  
- Add **search filters** (vehicle type, price, transmission, etc.).  
- Deliver a **fully tested** system with proper documentation within **8 weeks**.

## 🧠 Methodology

**Approach:** Hybrid — Waterfall (for planning and design) + Agile Scrum (for implementation).

- **Waterfall Phase (Weeks 1–2):** Gather requirements, design wireframes, and confirm project scope.  
- **Agile Scrum Phase (Weeks 3–8):** Four sprints of development, testing, and client feedback.  
- **Tools:** Jira for sprint tracking and GitHub for version control.  
- **Roles:**  
  - **Project Manager (Waruni Hewage):** Oversees progress and approvals.  
  - **Client (Tariq Khan):** Product owner, provides feedback and requirements.  
  - **Team Developers:** Build, test, and document features in weekly sprints.
